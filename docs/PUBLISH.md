# Публикация комплекта

Корень этого каталога — корень самостоятельного репозитория. В историю входят исполняемые модули, конфигурации, контрольные суммы, инструкции, численные карты и иллюстрации. Двоичные файлы моделей, для которых настроен Git LFS, при клонировании восстанавливаются командой `git lfs pull`. [Документация Git LFS](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage)

1. Откройте терминал в этом каталоге. Команды `git status` и `git lfs ls-files` показывают состояние исходников и перечень файлов под управлением LFS. При публикации укажите этот каталог как локальный репозиторий.
2. Для текущего комплекта подготовлена локальная папка `delivery/` — 141 часть общим объёмом 10,98 ГБ. Передайте все части вместе с копией проекта или приложите их к выпуску в GitHub Releases и укажите место получения в описании выпуска. Для повторной сборки из проверенного инвентаря выполните `python data_parts.py pack delivery`. Максимальный размер одной части — 512 МиБ. [О выпусках GitHub](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)
3. Получатель помещает части в `delivery/`, выполняет `python restore_lwnet.py`, `python data_parts.py restore delivery` и `python package_workspace.py verify`. Для отдельных исходных файлов Salinas используется зафиксированная версия репозитория авторов. Обученные веса и исходная N2N4M доступны через LFS. [Пошаговая инструкция](RUN.md)
4. В локальной папке `full_results/` лежат обе полные проверенные выгрузки, включая очищенные кубы и журналы. Для передачи всей вычислительной копии перенесите папку обычным копированием. Открытое представление в `results/` содержит карты без потерь и метрики по всем трём сценам и трём конфигурациям. [Каталог результатов](../results/README.md)

Размер каждого исходного файла и его полный SHA-256 хранятся в `workspace/input_inventory.json`. Для проверки отдельных частей в Linux выполните из корня комплекта `(cd delivery && sha256sum -c ../docs/DATA_PARTS.sha256)`. [Контрольные суммы частей](DATA_PARTS.sha256)

Ссылки на исходные наблюдения, публикации, авторов и условия сторонних материалов приведены в [описании источников](SOURCES.md).
