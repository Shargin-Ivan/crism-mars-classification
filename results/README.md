## Чтение результатов

`maps.npz` хранит массивы NumPy без изменения разрядности и без потерь. Для каждой ветви сохранены карта классов `class_map`, маска достоверного предсказания `prediction_valid_mask`, причина отказа `rejection_reason` и использованные каналы `used_channels`. В `classes.json` указаны соответствие идентификаторов классам, русские и исходные названия, цвета и контрольные суммы исходных файлов карт. Отрицательное значение обозначает отсутствие класса. Исходная LWNet использует собственные идентификаторы Salinas. Пример чтения из корня комплекта:

```python
import json
from pathlib import Path
import numpy as np

run = Path("results/epochs50/hymars_hc")
with np.load(run / "maps.npz", allow_pickle=False) as data:
    labels = data["lwnet_original_class_map"]
    accepted = data["lwnet_original_prediction_valid_mask"]
classes = json.loads((run / "classes.json").read_text(encoding="utf-8"))
taxonomy = classes["branch_taxonomy"]["lwnet_original"]
for class_id, count in zip(*np.unique(labels[accepted], return_counts=True)):
    print(classes["taxonomies"][taxonomy][int(class_id)]["ru"], int(count))
```

Для Холдена в архиве есть приведённая к общей нумерации разметка `gt_labels` и фиксированная маска оценки `gt_evaluation_mask`. В `per_class_gt.csv` приведены объём разметки, число верных и ошибочных ответов, точность, полнота, F1 и отказы по классам. Общая точность (`gt_oa`) учитывает все 20 090 размеченных пикселей. Макро-F1 усредняется по классам с разметкой. Для двух демонстрационных сцен графа точности по разметке остаётся пустой. Согласие с SAM на совместно классифицированных пикселях сопровождается долей такого пересечения.

## Полная выгрузка

В переносимой папке `full_results/main/` содержатся исходный эксперимент и серия 25 + 25, в `full_results/epochs50/` — серия 50 + 50. В них находятся подготовленные и очищенные кубы, исходные массивы карт, маски, матрицы ошибок, отчёты HTML, журналы и состояния обучения. Проверенные списки SHA-256 находятся в `full_results/checksums/`. Первая выгрузка включает 590 файлов, вторая — 463; суммарно 33,21 ГБ. У исторических конфигураций сохранены пути Linux, использованные во время эксперимента. Для нового прогона используются переносимые профили из инструкции.

Каталог `results/` входит в историю Git. Полные вычислительные выгрузки хранятся на диске отдельно от истории и могут передаваться вместе с комплектом. На исходной рабочей станции крупные неизменяемые массивы в `full_results/` связаны жёсткими ссылками NTFS с проверенным архивом эксперимента на том же томе. При чтении и переносе это обычные файлы. Для изменений следует сделать рабочую копию нужного массива. При наличии папки `full_results/` компактное представление можно заново собрать командой `python tools/build_results.py` в установленной среде Python 3.11 или новее.
